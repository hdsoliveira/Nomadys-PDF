Installation

Nomadys-PDF runs on Linux, on Wayland and X11. The command is npdf.

Dependencies#

sudo apt install build-essential pkg-config libsdl3-dev libfreetype-dev libfontconfig-dev zlib1g-dev

PDFium (the PDF engine) is downloaded automatically by the first make: a pinned release (chromium/8066 from bblanchon/pdfium-binaries), checked against its SHA-256. It is not stored in the repository.

Optional, for extra features:

ProgramUsed for
pdflatex (TeX Live) with amsmath, amssymbequations in comments (Highlights and comments)
synctex (comes with TeX Live)jumping between the PDF and the LaTeX source (LaTeX and VimTeX)
curl:bibtex (Quoting and citing)
CUPS (lp, lpstat)printing
xdg-openopening web links in the browser

Everything else works without them.

Building and installing#

git clone https://github.com/hdsoliveira/Nomadys-PDF.git
cd Nomadys-PDF
make              # builds ./npdf
make install      # installs for your user

make install puts, under ~/.local:

  • bin/npdf, the program
  • lib/nomadys-pdf/libpdfium.so, the PDF engine
  • share/nomadys-pdf/themes/, the colour themes
  • share/applications/npdf.desktop and the icons, so it appears in your application menu and can be chosen as the program for PDFs

Make sure ~/.local/bin is in your PATH.

make uninstall removes all of it. Your settings (~/.config/nomadys-pdf) and data (marks, recent files, the search index) are left alone; see Files, memory and speed to remove those too.

Updating#

git pull && make && make install

Making it the default PDF reader#

xdg-mime default npdf.desktop application/pdf

Checking the installation#

npdf --version      # Nomadys-PDF (npdf) 0.4.0
npdf --help         # a short list of keys and options
