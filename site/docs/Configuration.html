Configuration

Settings live in one plain text file, ~/.config/nomadys-pdf/config. It does not need to exist: every setting has a default. config.example in the source lists them all with comments; copy it to start:

mkdir -p ~/.config/nomadys-pdf
cp config.example ~/.config/nomadys-pdf/config
  • One setting per line: name = value.
  • # starts a comment (at the start of a line or after a space).
  • Colours are #RRGGBB.
  • A mistake is reported with its line number when the program starts, and the other lines still apply.
  • Changes apply the next time you open Nomadys-PDF; themes reload at once.

A font name that is not installed is reported, and a default is used.

Colours#

After the settings, [light] and [dark] sections set single colours of the light and dark mode, on top of the theme:

include = nord

[dark]
background = #101010
page_bg = #1C1C1C          # dark mode: the paper of the pages
page_fg = #E4E4E4          # dark mode: their ink

Every colour name, with what it paints, is listed in Themes and dark mode.

An example#

include = gruvbox
theme = dark
zoom = 125
pdf_dirs = ~/Papers, ~/Nextcloud/Library
highlight_colors = #FFE066, #FF8A80, #B9F6CA, #F8BBD0, #90CAF9
area_style = frame
cite_format = "%t" (p. %p)
font = JetBrains Mono
font_size = 11
leader = space

Older names#

Settings from earlier versions are still understood: highlight_color (the first colour only), background_light, background_dark, dark_contrast_low / page_low (the dark paper, as a grey level) and dark_contrast_high / page_high (the dark ink).
