Commands

Type : and the command. Tab completes command names and file paths; with several options they are listed above the line and Tab / Shift-Tab cycle through them. : followed by Tab lists every command.

Files and tabs#

CommandAction
:wsave
:qclose the tab
:q!close it, discarding unsaved changes
:wq, :xsave and close the tab
:e file.pdfopen a PDF in a new tab
:reloadread the PDF again from disk
:recentrecent files (\o)
:findfind any PDF in your folders (\f)
:sessionreopen the tabs of the last session
:print [pages] [xN] [@printer] [duplex]print, e.g. :print 3-7,10 x2 @office duplex

Moving and viewing#

CommandAction
:42, :page 42go to page 42
:zoom 150zoom in percent
:rotate 90, :rotate -90, :rotate 180turn the view
:dark / :lightdark / light mode
:pagespage grid (\g)
:presentpresentation (F5)
:marks, :notesthe panel (\l)
:nohremove the search highlighting

Split view#

CommandAction
:vsplit [file.pdf]split side by side: this PDF, or another
:split [file.pdf]split one above the other
:closeclose this pane
:onlykeep only this pane

Searching and comparing#

CommandAction
:library wordssearch the text of all your PDFs (\/)
:comments [words]search the comments and highlights of all your PDFs (\n)
:tasks [words]the tasks still to do in all your PDFs
:diff old.pdfcompare with an older version (]c [c go through the changes)
:nodiffhide the comparison

Notes, quotes and references#

CommandAction
:export [file.md] [colours] [commented] [tasks]highlights, comments and marks to Markdown (tasks as - [ ] / - [x])
:export! …the same, allowed to overwrite a file it did not write
:response [file.md]the response letter to the reviewers: their comments and your replies (r), by reviewer (more)
:response! …the same, allowed to overwrite a file it did not write
:merge copy.pdfbring in a co-author's highlights and comments
:bibtexcopy the paper's BibTeX entry (by its DOI or arXiv number)
:image file.pngput a picture on the page

Pages#

CommandAction
:extract 3-7 [file.pdf]pages 3–7 as a new PDF
:delete 3-7delete pages (u undoes it)
:insert other.pdfinsert another PDF after this page
:append other.pdfadd another PDF at the end

Page ranges: 5, 3-7, 10- (to the end).

Look and information#

CommandAction
:themechoose a theme (\T)
:theme NAMEswitch to a theme
:theme new NAMEmake your own theme from the current one
:aboutversion, author, contact (\a)
:helpevery key (\c)

From the terminal#

CommandAction
npdf file.pdf [more.pdf …]open files, each in a tab
npdfreopen the last session
npdf --export file.pdfprint its highlights and comments as Markdown
npdf --synctex-forward LINE:COL:FILE.tex file.pdfshow that source line (used by VimTeX)
npdf -x "COMMAND" file.pdfthe editor command for inverse search (%l %c %f)
npdf --version, npdf --helpversion, short help
