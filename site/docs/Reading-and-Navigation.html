Reading and navigation

Moving through a PDF#

KeyAction
j k (or ↓ ↑)scroll down / up
h l (or ← →)scroll left / right (when zoomed in)
Ctrl-d / Ctrl-uhalf a screen down / up
Ctrl-f / Ctrl-b, Spacea screen down / up
J / Knext / previous page
gg / Gfirst / last page
42G, 42gg or :42page 42
mouse wheelscroll

A number repeats a key: 5j, 3J.

Zoom and layout#

KeyAction
+ / - (or Ctrl + wheel)zoom in / out
=fit the width of the window
zfit the whole page
:zoom 150a zoom in percent
dtwo pages side by side (again: one page)
r / Rturn the view 90° clockwise / counter-clockwise
:rotate 90, :rotate -90, :rotate 180the same, by an angle
idark mode on / off (also :dark, :light)

Turning the view with r does not change the file. To turn pages in the file itself, use the page grid (Changing pages).

Each file remembers how you read it. Zoom, dark mode, two-page layout and rotation are kept per file and restored when you open it again, together with the page you were on. A file you never changed opens with the defaults of the configuration (zoom, theme). Turn this off with remember_view = false (and restore_position = false for the page).

Pages are drawn at the exact resolution of your screen (HiDPI included), never stretched. Very heavy pages (thousands of vector lines, dense plots) are drawn a little at a time, so scrolling and zooming never freeze: while such a page is being drawn, it shows how it looked at the previous zoom.

Dark mode#

i switches between the light and dark versions of the current theme. In dark mode the pages are recoloured, keeping hues (red stays red). Images are judged one by one: photos keep their colours, while figures drawn on white (plots, diagrams) are recoloured with the page so no white blocks glare. dark_images in the configuration changes this. Dark mode is remembered per file.

All pages at once: the page grid#

\g (or :pages) shows every page as a thumbnail.

KeyAction
h j k l, arrowschoose a page
J K, Ctrl-d Ctrl-ua screen down / up
gg / Gfirst / last page
+ / -bigger / smaller thumbnails
Entergo to that page (Ctrl-o returns)
Esc, q, \gclose

The grid is also where pages are deleted, turned, moved, extracted and inserted: see Changing pages.

Marks and jumps#

For going back and forth between places: the text, a figure, an equation, the references.

KeyAction
\ma, \mb, … \mzremember this place as mark a, b, …
ma, mb, …jump to that mark
mmback to where you were before the last jump (again: return)
Ctrl-o / Ctrl-iolder / newer place in the jump history

Every big move is a jump and goes into the history: gg, G, 42G, a search, a mark, a link, a contents entry, a page chosen in the grid. So Ctrl-o always brings you back.

Marks get a name from the first line of text where they were set; you can rename them in the panel. They are stored outside the PDF (keyed by its path), so they survive LaTeX recompiling the file; if pages are deleted or moved in the page grid, marks follow their pages.

Links, references and previews#

KeyAction
fletters appear on every link on screen; type one to follow it
Fthe same letters, but the target is previewed in a window, without leaving the page
clicka plain click on a link follows it

The letters go on every link of the PDF on screen: citations, references to figures, tables, equations and sections (papers made with LaTeX and hyperref, and most journal PDFs, have them), entries of a table of contents, and web links. Web addresses and DOIs written in the text as plain words get letters too. Following a link inside the PDF is a jump, so Ctrl-o comes back. Web links (http, https, www., mailto:, doi:) open in your browser; links to local files or programs are never run: they are shown and copied to the clipboard instead.

The preview (F) shows the target of a link inside the PDF (the figure, the equation, the bibliography entry) in a floating window, with a mark in the margin at the exact spot.

Key in the previewAction
j k, Ctrl-d Ctrl-uscroll it
Entergo there for real
Esc, qclose

While typing letters, Backspace undoes one and Esc cancels.

Presenting#

F5 (or :present) shows one page at a time, fullscreen, on black, with nothing else on screen.

KeyAction
j l Space → ↓ Enter PageDown, left clicknext slide
k h ← ↑ Backspace PageUp, right clickprevious slide
gg G 12Gfirst, last, slide 12
. or bblack screen (again: back)
Esc, q, F5stop; reading continues at that slide

The next slide is prepared while you talk, so moving forward is instant, even for heavy pages. Slides are drawn at the screen's full resolution; your reading zoom and place are untouched.

About#

\a (or :about) shows the version, the author and the contact address.
