What it does

Everything you do with a paper, one or two keys away

No toolbars, no menus, no sidebars. If you know vim, you already know how to move; if you do not, the help screen (\c) shows every key, and Esc always brings you back.

v · 8j · e e e · B · c

Highlights and comments, with real equations

A text cursor moves word by word; five colours sit under your left hand. Comments open next to the highlight, and anything between $…$ is typeset by LaTeX as you write.

  • Stored in the PDF as standard annotations: Acrobat, Okular, Zotero show them
  • Undo and redo everything, 200 steps deep
  • Filter by colour, export to Markdown for Obsidian
  • Merge a co-author's notes without duplicates

F · d · Enter · Ctrl-o

See a reference without losing your place

Press F: every citation, figure, equation and section reference on screen gets a letter. Type it, and the target opens in a window right there: the bibliography entry, the figure on page 7, the equation from the appendix.

  • f follows the link instead; Ctrl-o always comes back
  • Marks and a jump history, like in vim
  • Web links and DOIs open in your browser

Search the text of every PDF you own

"Where did I read about that?" \/ searches the text of all the PDFs in your folders as you type, and opens the right one at the right page, with the words highlighted. \n does the same with every comment you ever wrote.

  • An index built in the background, at low priority: about 16 ms per PDF, once
  • Afterwards only new and changed files are read again
  • \f finds any PDF by its name, fuzzy

:diff paper-v1.pdf · ]c ]c ]c

What changed since the submitted version?

:diff old.pdf compares two versions word by word: new text in green, changes in amber, deletions marked in red. ]c goes to the next change and tells you what it was: changed, was "3.2".

  • Ignores what is not a change: hyphenation, ligatures, page breaks
  • Updated every time LaTeX recompiles: answering reviewers becomes easy

The figure and the text, side by side

Split the window and keep the figure on one side while you read the text that discusses it, or open another paper next to it. Each pane has its own place, zoom and search.

  • Ctrl-w v, Ctrl-w s, Ctrl-w w: the keys of vim
  • Tabs, several windows, and your session restored on the next start

A dark mode that understands figures

Press i: text and plots are recoloured for the night, while photographs keep their colours. Nine colour themes (gruvbox, catppuccin, tokyonight, nord…), each with a light and a dark side, or your own.

  • Each file remembers its zoom, dark mode and page
  • Heavy pages render in slices: scrolling never freezes

Rearrange pages without another program

All pages as thumbnails with \g. Choose some, then move, turn or delete them, save them as a new PDF, or insert another PDF. Every change can be undone.

Install

Up and running in a minute

Nomadys-PDF builds from source on any recent Linux. The PDF engine (PDFium, the engine of Chrome) is downloaded and verified automatically.

1. Build and install

# Debian / Ubuntu
sudo apt install build-essential pkg-config libsdl3-dev \
     libfreetype-dev libfontconfig-dev zlib1g-dev

git clone https://github.com/hdsoliveira/Nomadys-PDF.git
cd Nomadys-PDF
make && make install

2. Open a paper

npdf paper.pdf          # or several: one tab each
npdf                    # your last session

3. Learn the keys as you go

\c shows every key of the mode you are in. The getting started guide takes five minutes, and the keyboard reference lists everything.

Optional: TeX Live for equations in comments and SyncTeX, curl for BibTeX, CUPS for printing.
